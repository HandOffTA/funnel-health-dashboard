# Funnel Health Dashboard

> Part of the [HandOffTA](https://github.com/HandOffTA) portfolio: practical AI tools for hiring teams.

## What It Does

Upload an ATS export CSV and instantly see time-in-stage, drop-off points, and stalled candidates across your hiring funnel.

## The Problem It Solves

Most ATS reporting is clunky or locked behind expensive add-ons. Teams can't easily see where candidates are getting stuck, which stages are slow, or which reqs are quietly stalling.

## Who It's For

TA leaders, recruiting ops, and recruiters who need a clear view of pipeline health without waiting on a BI team.

## How It Works

1. **Export from your ATS.** Pull a standard candidate/stage CSV.
2. **Upload the file.** The data is cleaned and normalized into a consistent stage model.
3. **Calculate the metrics.** Time-in-stage, stage-to-stage conversion, and drop-off rates are computed per req and overall.
4. **Flag stalled candidates.** Anyone sitting in a stage longer than a set threshold is surfaced so you can take action.

## Tools Used

- Looker
- SQL
- Google Sheets + Google Apps Script
